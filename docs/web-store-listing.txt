크롬 웹스토어 등록용 정보 — X HUB 3.3.1

<설명>
X HUB — 추첨, 팔로우 관리, 게시물 필터, 멀티 타임라인

X HUB는 X(트위터)에서 Raffle, Follow, Filter, Vertical 네 가지 도구를 제공하는 확장프로그램입니다. 별도의 X HUB 계정이나 서버 없이 브라우저에서 동작하며, X의 콘텐츠 요청에는 기존 X 로그인 세션을 사용합니다.

[주요 기능]
1. Raffle: 리포스트 참여자 목록 수집, 무작위 추첨, Follower Only 필터, TXT·CSV·JSON 내보내기.
2. Follow: 팔로워·팔로잉 목록을 스캔하여 일방 팔로우 관계 확인.
3. Filter: 인증 뱃지별 표시, 타임라인·상세·검색 범위 선택, 재게시·인용 숨김, 팔로우 화이트리스트.
4. Vertical: 홈·알림·북마크·탐색·검색·프로필·리스트를 최대 8열로 구성. 각 열의 독립 스크롤, 이동·확대·새로고침과 구성 저장. 검정·회색·흰색 및 보라색 강조를 사용하는 직각 UI.

목록 수집은 X에서 실제로 로드되는 데이터에 기반합니다. 로딩 지연·접근 제한·사이트 변경 등에 따라 전체 목록과 일치하지 않을 수 있습니다. Vertical의 콘텐츠와 버튼은 X의 원래 화면을 사용하며 X의 로그인 및 접근 권한이 필요합니다.

<전용 목적>
X 사용자가 같은 사이트에서 이벤트 추첨, 팔로우 관계 확인, 게시물 필터링 및 여러 타임라인 보기를 수행하도록 돕습니다.

<storage 권한>
Filter 설정, 팔로우 화이트리스트와 계정별 캐시, Vertical 열 구성·너비를 chrome.storage.local에 보관합니다. 자동 수집을 위해 생성한 탭 소유권은 chrome.storage.session에 저장합니다. 확장 자체의 서버로 해당 데이터를 전송하지 않습니다.

<declarativeNetRequestWithHostAccess 권한>
Vertical을 연 현재 탭의 X 출처 하위 프레임 요청 중 임시 토큰이 포함된 전용 요청에만 X-Frame-Options를 SAMEORIGIN으로 설정하여 같은 출처의 타임라인을 표시합니다. CSP는 변경하지 않습니다. 보기 종료, 탭 종료 또는 상위 화면 이동 시 임시 규칙을 제거합니다.

<호스트 권한>
https://x.com/*, https://twitter.com/*: X 페이지의 목록·게시물 DOM 분석, 스크롤 및 확장 UI 삽입, Vertical 열 표시.
https://api.x.com/*: 매니페스트에 선언된 X API 호스트 범위. 뱃지 정보는 페이지가 받은 응답을 MAIN world의 fetch 인터셉터가 관찰합니다. 확장 자체의 별도 서버로 API 응답을 전송하지 않습니다.
