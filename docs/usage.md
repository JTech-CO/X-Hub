# X Hub

> **X(트위터)를 위한 올인원 확장프로그램 - 추첨, 팔로우 분석, 트윗 필터링, 멀티 타임라인. 서버 불필요, 100% 클라이언트 사이드.**

## 1. 소개

**X Hub**는 X(트위터)에서 네 가지 도구를 하나의 플로팅 패널로 제공하는 Chrome 확장프로그램입니다. 모든 기능이 브라우저 내에서만 동작하며, 별도의 X HUB 계정이나 서버가 필요하지 않습니다. X의 로그인과 콘텐츠 요청은 기존 X 세션을 사용합니다.

**주요 기능**
- **MODE 1 · Raffle** - 리포스트 페이지를 자동 스크롤하여 리포스터를 수집하고 랜덤 추첨. Text / CSV / JSON 내보내기 지원.
- **MODE 2 · Follow** - 팔로워/팔로잉 페이지를 스캔하여 일방 팔로우 관계(맞팔 안 함 / 맞팔이 안 된 경우)를 감지.
- **MODE 3 · Filter** - 뱃지 등급(ALL / VERIFIED / NON-VER)에 따라 트윗을 숨기거나 표시. 타임라인·상세·검색 범위 지원. 팔로우 화이트리스트로 내 팔로우 네트워크는 항상 예외 처리.
- **MODE 4 · Vertical** - 홈·알림·북마크·탐색·검색·프로필·리스트를 최대 8개 열로 구성. 화면 너비에 따라 4~5열 동시 보기, 독립 스크롤, 열 확대·이동·삭제·새로고침 및 구성 저장.
- **자동 최소화** - 재게시/좋아요 페이지에서는 MODE 1, 팔로워/팔로잉 페이지에서는 MODE 2를 자동 전체 표시. 그 외 화면에서는 X HUB 로고 버튼으로 자동 최소화.
- **검색 & 정렬** - 핸들, 닉네임, 바이오 기반 실시간 필터링 및 정렬.
- **Follower Only 추첨** - 나를 팔로우하는 유저만 추첨 풀에 포함.

## 2. 기술 스택

| 항목 | 내용 |
|---|---|
| 플랫폼 | Chrome 확장프로그램 - Manifest V3 |
| 언어 | Vanilla JavaScript (ES2020+) |
| UI | Shadow DOM (X 페이지 스타일과 완전 격리) |
| 타이포그래피 | 로컬 시스템 폰트 (외부 폰트 요청 없음) |
| 저장소 | `chrome.storage.local` (Filter 설정·화이트리스트, Vertical 열 구성), `chrome.storage.session` (수집 탭 소유권) |
| 디자인 | X의 디자인에서 영감을 받은 고대비 다크 테마 |

## 3. 빠른 시작

**요구 사항**: Chromium 기반 브라우저 (Chrome, Edge, Brave 등)

### 설치 (개발자 모드)

1. **클론**
   ```bash
   git clone https://github.com/jtech-co/X-Hub.git
   ```
2. `chrome://extensions` 열기
3. 우측 상단 **개발자 모드** 활성화
4. **압축 해제된 확장 프로그램 로드** 클릭 후 클론한 저장소의 **dist** 폴더 선택

### 사용법

| 모드 | 사용 위치 | 시작 방법 |
|---|---|---|
| **Raffle** | `x.com/*/status/*/retweets` 또는 `/likes` | 패널이 자동으로 펼쳐짐 → **Start** 클릭 |
| **Follow** | `x.com/*/followers` 또는 `/following` | 패널이 자동으로 펼쳐짐 → **Start Scan** 클릭 |
| **Vertical** | `x.com/*` | 미니 패널의 **Vertical** 또는 Vertical 모드 → 열 추가 |
| **Filter** | `x.com/*` 전체 페이지 | 미니 버튼 클릭 → 패널 펼침 → **Filter** 모드로 전환 → ALL / VERIFIED / NON-VER 선택 |

> **패널 최소화**: 리포스트·좋아요·팔로워·팔로잉 외의 화면(홈, Grok 등)에서는 패널이 자동으로 우측 상단의 **X HUB 로고 버튼**으로 최소화됩니다. 클릭하면 펼쳐지고, 헤더의 `−` 버튼으로 다시 최소화할 수 있습니다.

## 6. Vertical 사용과 권한

- **Vertical**는 X HUB의 자체 멀티 타임라인 보기입니다. 기존 X 로그인 세션으로 여러 타임라인을 동시에 표시합니다.
- 홈·알림·북마크·탐색을 기본으로 제공합니다. **열 추가**에서 검색어, @아이디, 리스트 ID/URL을 입력할 수 있습니다.
- 열은 최소 360px을 확보합니다. 공간이 부족하면 가로 스크롤을 사용하며, `⛶`로 한 열을 확대할 수 있습니다. 각 열 안에서는 X의 원래 좋아요·답글·재게시·공유 UI를 사용합니다.
- X의 서비스 워커가 일부 경로를 캐시하므로, 열은 북마크 진입점에서 X 화면을 초기화한 뒤 해당 열의 경로로 이동합니다.
- `declarativeNetRequestWithHostAccess` 권한은 열 로드를 위해 필요합니다. 현재 탭 + X 출처 + 임시 토큰이 포함된 하위 프레임 요청에만 `X-Frame-Options: SAMEORIGIN`을 적용합니다. CSP는 수정하지 않습니다. 보기 종료·탭 종료·상위 화면 이동 시 세션 규칙을 제거합니다.
- `기본 화면으로`를 누르면 열 문서와 임시 규칙을 제거하고 원래 X 화면으로 돌아갑니다. 열의 구성과 너비만 저장하며 게시물 내용은 저장하지 않습니다.
- X의 로그인, 접근 권한, 사용량 제한 및 사이트 변경의 영향을 받습니다. 로드 실패 시 열 새로고침 또는 새 탭 열기를 이용하세요. 열을 많이 열면 메모리와 네트워크 사용량도 증가합니다.

## 7. 개발 검증

```powershell
npm test
npm run preview
```

로컬 레이아웃 검증 페이지: `http://127.0.0.1:8765/home` (실제 계정과 무관한 가상 데이터).
확장 스크립트나 매니페스트를 변경했다면 확장 관리 화면에서 X HUB를 새로고침하고 X 탭도 새로고침해야 합니다.
수정 내역과 검증 범위는 [점검 보고서](audit.md)를 참고하세요.

### 3.3.1 디자인 적용 확인

Vertical 툴바에 `v3.3.1`이 표시되고, 검정 배경·보라색 외곽선·직각 모서리가 보이면 최신 디자인입니다.
파란색 버튼이 보이면 이전 content script가 실행 중입니다. 확장 관리 화면의 **X HUB 카드 새로고침**으로 버전 3.3.1을 확인한 뒤 X 탭을 새로고침하세요.
